## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

# Project Instructions

## Project
Build a minimal, user-friendly online SQL practice platform.

## Reference
https://www.sql-practice.com/

## Technology
- Astro
- TypeScript
- Tailwind CSS
- CodeMirror 6
- sql.js
- Web Workers
- Vanilla JavaScript

## Important Rules
- Use Astro only. Do not use React or Next.js.
- Prioritise clean, minimal UI.
- Keep the website lightweight.
- SEO is a major priority.
- Use reusable Astro components.
- Use TypeScript wherever practical.
- Avoid unnecessary dependencies.
- Do not create unnecessary features.
- Ensure mobile responsiveness.
- Never compromise SQL execution reliability.

## Product Priorities
1. Reliable SQL playground.
2. Easy database selection.
3. Clear SQL query results.
4. Practice questions.
5. Helpful answer validation.
6. Technical SEO and performance.

## Development Rules
- Work phase by phase.
- Inspect existing code before modifying it.
- Do not rewrite unrelated files.
- Run tests after significant changes.
- Run the production build before completing a major phase.
- Explain important architectural decisions.
